# 🐢 거북놈 (nom_detector)

> **웹캠 하나로 시작하는 자세 교정 파트너**  
> 숭실대학교 전자공학기초실험

---

## 프로젝트 소개

장시간 컴퓨터 앞에 앉아 있으면 자신도 모르게 거북목 자세가 된다.
거북놈은 웹캠으로 사용자의 자세를 실시간 분석하고, 무너지는 순간 단계별로 경고를 보내는 자세 교정 도우미다.

- 📷 **실시간 감지** — 웹캠으로 현재 자세를 즉시 분석하고 경고
- 🎯 **개인 맞춤** — 체형별 캘리브레이션으로 나만의 자세 기준 설정
- 🚨 **3단계 경고** — NORMAL → WARNING → DANGER 단계별 알림

---

## 주요 기능

### 3단계 경고 시스템

| 단계 | 상태 | 설명 |
|------|------|------|
| 🟢 NORMAL | 정상 | 올바른 자세 유지 중 |
| 🟠 WARNING | 주의 | 자세가 기준에서 벗어나기 시작 |
| 🔴 DANGER | 위험 | 즉시 자세 교정 필요 |

### 듀얼 모니터링 모드

- **포그라운드 모드** — 실시간 자세 피드백 화면 표시
- **백그라운드 모드** — 화면 없이 백그라운드에서 경고만 전달

### 자세 통계

언제, 얼마나 자주 자세가 무너지는지 패턴을 분석하여 시각화한다.

---

## 시스템 구조

```
nom_detector/
├── core/         # 핵심 로직 (캘리브레이션, 경고 판단)
├── vision/       # 웹캠 영상 처리 및 자세 감지
├── stats/        # 자세 통계 수집 및 분석
├── ui/           # 메인 화면, 경고 UI
└── animations/   # 단계별 경고 애니메이션
```

중간 발표 이후 단일/혼합 구조에서 기능별 모듈로 전면 분리하여 유지보수성을 높였다.

---

## 개발 과정에서 해결한 문제들

| 문제 | 원인 | 해결 방법 |
|------|------|-----------|
| 화면 멈춤 | 카메라 연산 부하 | 연산과 화면 렌더링 스레드 분리 |
| 백그라운드 전환 후 경고 폭주 | 캘리브레이션 미완료 상태에서 전환 | 캘리브레이션 완료 후에만 전환되도록 흐름 재설계 |
| 경고 깜빡임 | 자세 흔들림으로 인한 잦은 상태 변화 | 최근 N프레임 평균으로 안정화 |
| 통계 화면 한글 깨짐 | 폰트 미설정 | 폰트 설정부터 레이아웃까지 전면 재설정 |

## 실행 방법

```bash
pip install -r requirements.txt
python main.py
```

처음 실행 시 캘리브레이션을 완료해야 자세 감지가 시작된다.
